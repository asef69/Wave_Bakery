The served dish, end to end

m = (1/√K)·Σₖ H_wash{ xₖ }            (wash, then mix)
c = A·m(α(t − t₀)) * h + b(t)         (season, marinate, cook)
y = H_cart{ IDFT{ Q·DFT{c} } + v(t) }  (oven, then cart)

b = burnt overtone, v = road vibration. The reference y_ref is this same chain on clean ingredients with the recipe’s ideal dials. 5 recipes · 3 tiers · 4 difficulties (7:00 → 2:00).

Theory · Stations 1–3

Generate, wash, mix

01 · Generate

Ingredients are signals

x[n] = x(n/400), n = 0…400
sq  = (4A/π)·Σ sin(2πkft)/k
tri = (8A/π²)·Σ ±sin(2πkft)/k²
k = 1, 3, 5, …  (odd harmonics)
x_d(t) = x(t) + n(t)

Parametric curves use y(t); the chicken is a real 44.1 kHz recording.

02 · Wash

Washing is low-pass filtering

Y(f) = H(f)·X(f)
H = 1,  if f ≤ f_c
H = ½[1 + cos(π(f − f_c)/w)]
H = 0,  if f ≥ f_c + w
w = max(30, 0.15·f_c)
prep = 55%·removed + 45%·kept

Pass mark: cleanliness ≥ 85 %.

03 · Mix

The bowl is superposition

m[n] = (1/√K)·Σₖ xₖ[n]
K = 1  →  m[n] = x₁[n]
curve = (Σₖ Xₖ(u), Σₖ Yₖ(u))
mix% = |bowl∩recipe|/|recipe|

1/√K keeps K ingredients about as loud as one; curves add as 2-D paths.

square: odd harmonics, 1/k

triangle: odd harmonics, 1/k²

dirty: x(t) + n(t)

washed: H·X, noise removed

Theory · Stations 4–6

Season, marinate, cook

04 · Season

Amplitude and time scaling

s(t) = A·m(αt)
S(f) = (A/|α|)·M(f/α)
α > 1: compressed, higher f
acc = 100 − 70·(ΔA/A* + Δα/α*)

No rescaling afterwards, so a level mistake stays visible.

05 · Marinate

Time shift

r(t) = m(t − t₀)
R(f) = M(f)·e^(−j2πft₀)
d = round(t₀/3 · N) samples
acc = 100 − 150·Δt₀/t₀*

The server delays by fractional samples with this linear phase ramp.

06 · Cook

Cooking is LTI convolution

y[n] = Σₖ x[(n−k−s) mod N]·h[k]
k = 0…95,  Σ|h[k]| = 1
s = round(30τ),  τ = depth
out = (1 − w)·x + w·y
w = min(1, 1.15τ)

The impulse response h[n] of each appliance is drawn below.

grill: an echo comb

fry: a bright burst

bake: e^(−((k−16)/14)²)

boil: a damped resonator

Theory · Station 7

Precision Oven: sampling, DFT and the notch

07 · Sample and transform

b[n] = a_d·max|x|·sin(2π·f_d·n/400)
f_d = ρ·f₀   (between two harmonics)
f_s ≥ 2·f_max   (Nyquist)
f_alias = |f − round(f/f_s)·f_s|
X[k] = Σₘ x[m]·e^(−j2πkm/N)
f_k = k·f_s / N

07 · Filter and rebuild

X'[k] = X[k]·G_band·C(f_k)·Q(f_k)
Q(f) = 1 − 0.98 / (1 + ((f − f_n)/1.5)²)
C(f) = e^(−((f − f_c)/4)²),  f > f_c
X'[N−k] = conj(X'[k])   (real output)
x'[m] = (1/N)·Σₖ X'[k]·e^(j2πkm/N)
x_out(t) = Σₘ x'[m]·D_N(t − m/N)

harmonics every 4 Hz · burnt overtone at 18 Hz · dashed: the notch gain Q(f) · 0 → 32 game Hz

Theory · Station 8

System Delivery: poles, zeros and stability

08 · The cart as a filter

v[n] = x[n] + a_r·max|x|·cos(ω_r·n)
ω_r = 2π·f_r / 8000   (burger: 2600 Hz → 2.04 rad)
H(z) = g·(z − e^{jω₀})(z − e^{−jω₀})
     / (z − 0.85e^{jω₀})(z − 0.85e^{−jω₀})
y[n] = Σₖ bₖ·x[n−k] − Σₖ aₖ·y[n−k]
|H(e^{jω})| = g·Πᵢ|e^{jω} − zᵢ| / Πⱼ|e^{jω} − pⱼ|
stable ⇔ every |pⱼ| < 1   (BIBO)
low-pass: H(z) = (1 − r)·z / (z − r)
sensor: f_a = |f_r mod f_s|, folded to [0, f_s/2]

The z-plane

zeros cancel the road · poles at 0.85 keep it narrow
dashed: the aliased reading of a 1.2 kHz sensor

Implementation

How a dish becomes a score

Dish match (server)

SNR  = 10·log₁₀(Σt² / Σ(t − p)²)
corr = max over ℓ of (t ⋆ p)[ℓ] / (‖t‖·‖p‖)
spec = cos∠(T_dB, P_dB), 40 dB window
m = 40%·S + 35%·C + 25%·N

S = (spec − 0.6)/0.38, N = (SNR + 5)/30, each clipped to 0–1

Final score

raw   = m·(0.72 + 0.28·prep/100)
score = 100·(raw/100)^(1/tol)
stars at 92 / 80 / 66 / 50 / 32

Washing scales the dish, so it cannot carry a ruined one.

Overall score

total = round(10·score·d)
      + round(min(2·s_left, 300)·d)
d = 0.8 · 1.0 · 1.25 · 1.5

Easy → MasterChef; the leaderboard ranks this number.

Live match (in every lab)

r = Σ(x−μx)(y−μy) / √(Σ(x−μx)²·Σ(y−μy)²)
NRMSE = 1 − RMSE / (max y − min y)
live = 50·max(0, r) + 50·NRMSE
