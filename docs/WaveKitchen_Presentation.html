Signals and Systems is taught as equations you cannot see or hear

Convolution

is a formula on the board, not something you can hear.

Aliasing

is a warning in the textbook, not a mistake you make.

Theory · Stations 1–5

Wash, mix, season, marinate

Washing

Low-pass filtering

Y(f) = H(f)·X(f)

Noise arrives added, x + n. Too low a cutoff cuts the ingredient itself.

Mixing

Superposition

y = (1/√K)·Σ x_k

The bowl is linear; 1/√K keeps loudness comparable. Curves add as 2-D paths.

Seasoning

Amplitude and time scaling

y = A·x(αt)
↔ (A/|α|)·X(f/α)

α > 1 compresses time and moves energy up in frequency.

Marinating

Time shift

y = x(t − t₀)
↔ X(f)·e^(−j2πft₀)

A pure delay; the server shifts by fractional samples with a phase ramp.

Ingredients are textbook signals: square and triangle waves (odd harmonics falling as 1/n and 1/n²), sums of sines, 2-D parametric curves and one real 44.1 kHz recording.

Theory · Station 6

Cooking is convolution

y[n] = Σ x[k] · h[n − k]

An LTI system is fully described by its impulse response h. Each appliance is a different h; the player slides h across x and watches the output build up.

Grill

A comb of echoes

Fry

A bright, fast-decaying burst

Bake

A smooth long tail: a low-pass

Boil

A damped resonator

Kernels: 96 taps with Σ|h| = 1, so cooking reshapes the dish without changing its level.

Theory · Stations 7–8

Finishing: the oven and the cart

Precision Oven

Sampling · DFT · notch · inverse DFT

  1. Sample at f_s ≥ 2·f_max, or the dish aliases
  2. DFT: bins at f_k = k·f_s/N
  3. Spot the burnt overtone between two harmonics (burger: 18 Hz, between 16 and 20)
  4. Notch it: gain 1 − 0.98 / (1 + (Δf/1.5)²)
  5. Inverse DFT: the rebuilt dish is served

System Delivery

Poles, zeros, stability, aliased sensing

H(z) = g·(z − e^(jω₀))(z − e^(−jω₀))
/ (z − 0.85e^(jω₀))(z − 0.85e^(−jω₀))

  • Road tone: burger 2600 Hz at 8 kHz, ω₀ ≈ 2.04 rad
  • Zeros on the unit circle at ±ω₀ remove it; poles at 0.85 keep the notch narrow
  • A pole with |p| ≥ 1 is unstable: the output grows
  • A 1.2 kHz sensor reads 2600 Hz as 200 Hz: a notch there misses

Architecture and key decision

The browser plays. The server judges.

Browser: plays

React 19 · TanStack Router/Start · TypeScript · Vite

  • The DSP pipeline for every station
  • Graphs and Web Audio playback
  • Run state in localStorage
  • Works offline with a local score

JSON over /api

settings: bowl, cutoffs, dials, appliance, notch, poles

scores, stages, ranks

Server: judges

FastAPI · SQLAlchemy · SQLite · NumPy/SciPy

  • Seeded dirty ingredients per session
  • Rebuilds and scores the dish
  • Points, ranks and tier unlocks
  • The leaderboard

The browser sends settings, never scores. The server recreates the dirty ingredients from the session seed, runs the same pipeline as the reference, claims each dish once and times the bonus on its own clock.

Implementation

How a dish becomes a score

Dish match (server)

m = 0.40·spec + 0.35·corr + 0.25·SNR

dB spectra compared over the 40 dB below the target’s peak, correlation, SNR scored from −5 to 25 dB; both dishes on the reference scale, so the seasoning level counts

Final score

raw = m·(0.72 + 0.28·prep/100)

score = 100·(raw/100)^γ

Washing scales the dish, so it can’t carry a ruined one; γ = 1 / recipe tolerance; stars at 92 / 80 / 66 / 50 / 32

Overall score

total = score·10·d + min(2·s, 300)·d

d = 0.8 / 1.0 / 1.25 / 1.5 from Easy to MasterChef, s = seconds left; the leaderboard ranks this

Live match in each lab

0.5·max(0, ρ) + 0.5·(1 − RMSE/range)

ρ = Pearson correlation with the target; instant feedback while you play

Implementation

Decisions and features

Hard problems we solved

  • Cart started cold: a steady-state response cut the start-up error from about 100 % of the peak to under 5 %
  • Oven lost content above f_s/2: the equaliser now acts on the full dish, so a perfect finish keeps 99–100 %
  • Normalising hid seasoning mistakes: every comparison uses one common scale
  • Score page and leaderboard disagreed: one overall score, computed and stored by the server

What the game offers

  • 5 recipes, 3 tiers and 4 difficulties, each with a timer, a start countdown and pause
  • Accounts, ranks, tier unlocks and a seasonal leaderboard: top 5, then See all
  • Every signal can be heard; cooking sounds play while you convolve
  • Signal Playground: 10 labs, including the oven, the z-plane, tasting and a full recipe chain
  • Works offline with a local score
