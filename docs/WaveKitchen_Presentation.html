Theory · Stations 1–2

Ingredients, noise and washing

Ingredients are textbook signals

  • Square wave: odd harmonics, 1/n (sugar, salt)
  • Triangle wave: odd harmonics, 1/n² (cheese)
  • Sums of sines: bread = 3 Hz + 9 Hz
  • 2-D parametric curves: noodles, onion, egg
  • A real recording: chicken, 44.1 kHz PCM

Washing is low-pass filtering

Y(f) = H(f) · X(f)

  • Noise arrives added: x(t) + n(t)
  • Drag the cutoff across the spectrum
  • Too low a cutoff cuts the ingredient itself
  • Server prep score: 28 % of the dish score

Theory · Stations 3–5

Mix, season, marinate

Mix: superposition

y = (1/√K) · Σ x_k

The bowl is linear: add the ingredients and scale by 1/√K to keep loudness comparable. Curves like noodles add as 2-D (x, y) paths.

Season: scaling

y = A · x(αt)

↔ (A/|α|) · X(f/α)

Two dials: amplitude A and rate α. α > 1 compresses time and moves energy to higher frequencies.

Marinate: time shift

y = x(t − t₀)

↔ X(f) · e^(−j2πft₀)

A pure delay. The server shifts by fractional samples with a linear phase ramp.

Crème Brûlée, Feast: amplitude modulation x(t)[1 + m cos 2πf_c t] adds sidebands at f ± f_c.

Salad, Feast: decimation by M; skip the anti-alias filter and content above f_s/2M aliases.

Theory · Station 6

Cooking is convolution

y[n] = Σ x[k] · h[n − k]

An LTI system is fully described by its impulse response h. Each appliance is a different h; the player slides h across x and watches the output build up.

Grill

A comb of echoes

Fry

A bright, fast-decaying burst

Bake

A smooth long tail: a low-pass

Boil

A damped resonator

Kernels: 96 taps with Σ|h| = 1, so cooking reshapes the dish without changing its level.

Theory · Station 7

Precision Oven: remove the burnt overtone

dish harmonics (every 4 Hz)

burnt overtone, 18 Hz

x-axis: 0 → 32 game Hz · dashed line: the notch filter gain

  1. Sample at f_s ≥ 2·f_max (at most 64 Hz), or the dish aliases
  2. DFT: bins at f_k = k·f_s/N (zero-padded radix-2 FFT)
  3. Spot the spike the target does not have: it sits between two harmonics (burger: 18 Hz, between 16 and 20)
  4. Notch it: gain 1 − 0.98 / (1 + (Δf/1.5)²)
  5. Inverse DFT: the rebuilt dish is what gets served

Theory · Station 8

System Delivery on the z-plane

zeros at ±ω₀

poles at r = 0.85

dashed: the aliased sensor reading

H(z) = g · (z − e^(jω₀))(z − e^(−jω₀)) / (z − re^(jω₀))(z − re^(−jω₀))

  • The road adds a tone: burger 2600 Hz at 8 kHz, so ω₀ = 2π·2600/8000 ≈ 2.04 rad
  • Zeros on the unit circle at ±ω₀ remove it; poles at r = 0.85 keep the notch narrow
  • g normalises the gain to 1 where the dish lives, so the dish passes untouched
  • A pole with |p| ≥ 1 is unstable (not BIBO): the output grows and the dish is ruined
  • A 1.2 kHz sensor reports 2600 Hz as 200 Hz (aliased): a notch there misses

Key design decision

The browser plays. The server judges.

Never trusts the client

The browser sends settings, never scores. A client-reported accuracy is ignored, and a test proves it.

Rebuilds from scratch

Seeded dirty ingredients and the player settings run through the same pipeline as the reference.

Fair by construction

A dish is claimed atomically, the time bonus runs on the server clock, and locked-tier runs earn no points.

Implementation

How a dish becomes a score

Dish match (server)

m = 0.40·spec + 0.35·corr + 0.25·SNR

Spectral similarity of dB spectra, correlation, SNR scored from −5 to 25 dB; both dishes on the reference scale, so the seasoning level counts

Final score

raw = 0.72·m + 0.28·prep

score = 100·(raw/100)^γ

γ = 1 / recipe tolerance; stars at 92 / 80 / 66 / 50 / 32

Overall score

total = score·10·d + min(2·s, 300)·d

d = 0.8 / 1.0 / 1.25 / 1.5 from Easy to MasterChef, s = seconds left; the leaderboard ranks this

Live match in each lab

0.5·max(0, ρ) + 0.5·(1 − RMSE/range)

ρ = Pearson correlation with the target; instant feedback while you play

Hard problems we solved

Mixing curve lost between labs

Carried the 2-D mixing curve through seasoning, marinating and cooking.

Normalising hid seasoning mistakes

Removed per-stage rescaling; dishes are compared on one common scale.

Cart filter started cold

Steady-state periodic response: start-up error of about 100 % of the peak is now under 5 %.

Oven lost everything above f_s/2

The equaliser now acts on the full dish; a perfect finish matches the convolved dish at 95–100 %.

The notch amplified the dish ×1.17

Gain normalised at DC or Nyquist, whichever is far from ω₀.

Score page and leaderboard disagreed

One overall score, computed and stored by the server, shown in both places.

Reflection

Limitations and next steps

Limitations

  • Browser and server build ingredients differently: same parameters, different samples
  • The live match is mostly shape-based: seasoning 20 % too strong still shows about 97 %
  • Chop Lab aliasing is simulated in the browser; only the server truly decimates
  • The beamforming sandbox and direct DSP endpoints are not part of scoring

Next steps

  • One shared signal model for browser and server
  • Weight amplitude in the live match
  • Real frequency folding in the Chop Lab
  • A teacher mode with custom recipes and targets
